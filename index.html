Матрица оснований: 92 организованности

Многоходовочка, Онтоклуб «108». Материал — kruty-organizovannosti-88.md, ход работы — hod-raboty.md.
Как читать. Выберите два основания: одно задаёт строки, другое столбцы. Все 92 организованности раскладываются по этой паре заново, и у каждой пары свои клетки и свои позиции. В клетке стоит список позиций. Жирная позиция с пометкой ×N встретилась у N организованностей этой клетки. Пусто: пример не нашёлся, из этого ещё не следует, что его нет. Клик по клетке показывает организованности по позициям, клик по позиции открывает её разбор.
Даты, факты и статус Д/Р взяты из проверенного дока. Разметка организованностей по основаниям и название позиции — моя интерпретация. Надёжность оснований разная: объект, эпоха, носитель и происхождение знания довольно конкретны, философская платформа и философский триптих для древних организованностей сильно спекулятивны. Разбор позиций по вопросам тоже интерпретация; где ответа нет, так и написано.
Прогноз до 2050: сведение оптик циклов и СРТ
Каждая пятилетка получает фазу по календарю оптики. Позиция попадает в клетку по двум независимым линиям: логика фазы (признаки фазы требуют класса работы, который делает позиция) и прецедент (в той же фазе прошлых циклов позицию давали организованности из материала).
Сквозная находка: вневременные метапозиции
Позиции, которые повторяются в организованностях, далёких друг от друга по времени. Список собирается из материала автоматически: позиция встречается в четырёх и более эпохах.
Противоположная находка: позиции без прецедента
Встречены только в блоке VI, в этой выборке раньше аналога нет.
